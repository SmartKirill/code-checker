# CodeStep — тренажёр программирования

CodeStep — учебный веб-проект, предназначенный для развития практических навыков программирования.

С помощью тренажёра ученики могут выбирать язык программирования, решать задания, писать собственный код и получать обратную связь.

## Возможности сайта

- Поддержка четырёх языков: Python, C, C++ и Java.
- Выбор начального или продвинутого уровня сложности.
- Получение практических заданий из подготовленного набора.
- Встроенный редактор программного кода.
- Предварительная проверка решений.
- Подсказки при обнаружении типичных ошибок.
- Возможность исправить решение и проверить повторно.
- Переход к следующему заданию.
- Возможность пропустить задание.
- Подсчёт решённых и пропущенных заданий.

## Структура проекта

- `app/page.tsx` — главная страница с описанием CodeStep.
- `app/training/page.tsx` — страница тренировки с заданиями и редактором.
- `app/layout.tsx` — общий макет приложения.
- `app/globals.css` — глобальные стили.

## Запуск проекта

Для запуска необходимы Node.js и pnpm.

1. Установить зависимости командой `corepack pnpm install --frozen-lockfile`.
2. Запустить сервер командой `corepack pnpm dev`.
3. Открыть в браузере `http://localhost:3000`.

Страница тренажёра находится по адресу `http://localhost:3000/training`.

Для проверки сборки используется команда `corepack pnpm build`.

## Как работает проверка кода

В текущей версии используется предварительная проверка структуры программного кода.

Система анализирует наличие основных конструкций, необходимых для решения задания, и выдаёт подсказки при обнаружении типичных ошибок.

**Важно:** написанные программы пока не выполняются. Успешная предварительная проверка не гарантирует правильность программы на всех входных данных.

В дальнейшем планируется подключение серверного выполнения кода и проверки решений с помощью тестовых данных.

## Назначение проекта

CodeStep создан в рамках командного учебного проекта по программированию. Его цель — сделать практику написания кода доступной, понятной и интерактивной.
